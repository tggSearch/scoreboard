# 翻译检查脚本使用说明

## 概述
`check_translations.dart` 是一个用于检查和管理多语言翻译完整性的脚本。

## 功能
- 检查所有语言文件相对于中文的翻译完整性
- 自动补充缺失的翻译键
- 显示各语言的翻译统计信息
- 支持中文、英文、日文、韩文、法文、德文

## 使用方法

### 运行检查
```bash
cd score_board_pro
dart scripts/check_translations.dart
```

### 输出示例
```
🔍 开始检查翻译完整性...

📊 翻译完整性检查结果:
中文翻译键总数: 518
英文翻译键总数: 666
日文翻译键总数: 519
韩文翻译键总数: 519
法文翻译键总数: 519
德文翻译键总数: 519

✅ 所有语言的翻译都是完整的！
```

## 添加新语言

1. 创建新的翻译文件，例如 `es_es.dart`（西班牙语）
2. 在 `translation_manager.dart` 中添加导入和映射
3. 在 `language_controller.dart` 中添加支持
4. 在 `translations.dart` 中添加导入和键值对
5. 更新检查脚本以包含新语言
6. 运行检查脚本自动补充缺失翻译

## 注意事项
- 脚本会自动为缺失的翻译键生成占位符 `[中文内容]`
- 建议手动完善占位符翻译
- 每次添加新语言后都应运行此脚本检查完整性
